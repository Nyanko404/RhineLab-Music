# 陣列懸停、拖動與滾輪

2026-09-10。沿用已批準的參考視頻與原生實現流程。

## 交互

- 鼠標命中卡片時額外豎直抬起 0.28，約 200ms 顯現，移開后平滑回落。反饋按循環陣列的實際位置保存，選中模型、陣列實例和歸位副本共享同一高度，不改變詳情抽取進度或鏡頭目標。
- 鼠標左鍵、觸摸與筆使用同一組 Pointer Events。7px 內保留點擊，10px 后自由拖動；已經移動過的手勢回到起點也不當作點擊。
- 用戶最新選擇自由平面跟隨，取消屏幕橫豎快捷手勢和斜向鎖軸。以選中模型中心采樣兩個軌道的 CSS 投影，逆矩陣同時計算列與檔案位移。投影在手勢內固定，允許水平、豎直、任意斜向及中途轉彎；無效或退化投影不開始拖動。
- 兩個軌道同時由指針或慣性持有，選檔不能引發額外鏡頭吸附。沿實際經過的物理格位選檔并更新列內記憶，按鈕／鍵盤切列仍使用該列記憶。
- 拖動連續改變原有橫向與前后軌道。用戶進一步要求網頁快速滑動的持續慣性：松手后以實際速度繼續運動，速度按 `exp(-2.4 × 秒數)` 衰減，不再預選遠處目標或限制最多兩列／三檔。檔案隨實際經過的位置依次切換，沿用標題、聲音、波浪、歸位和各列記憶；速度低于 0.6 格/秒后，才以速率 10 的臨界阻尼彈簧吸附到最終整數位置。
- 松手速度來自最近 120ms 的指針樣本，包含可用的合并事件并使用事件時間戳；反向時從轉折點重新估算。相同距離，拖得越快，繼續滾動越遠；停止移動超過 80ms 再松手不追加慣性。再次按住立即停止并保留當前軌道位置，尚未拖過方向閾值時也不會自動回彈；點擊接住慣性不會誤選其他卡片。鍵盤、滾輪、模式切換和減少動態效果設置會中止慣性。
- 雙向速度共享自由衰減階段，保留屏幕中的滑行方向；整體放慢后共同吸附。再次按下同時接住兩個軌道。
- 滾輪向上切上一檔、向下切下一檔。像素、行和頁單位歸一化，累計 100px 切一檔，單事件最多三檔；停頓或反向清除舊的累計量。Ctrl+滾輪和主要橫向的觸控板事件不截獲。
- 捕獲丟失、pointercancel、窗口失焦、窗口尺寸變化或新增第二根手指時，停止拖動并吸附；后續單指可繼續。詳情仍在凈空足夠后拖動旋轉；正文和彈窗不會觸發陣列切檔。

實現：`src/archive-drag.ts`、`src/scene.ts`。原來的松手后單步 swipe 判斷已移除。

## 驗證

本次自由拖動：純邏輯、桌面及手機橫豎屏自由路徑、鼠標及觸摸快慢慣性、懸停與輸入回歸、生產構建通過。桌面另驗證雙向慣性比例及同時接住兩個軌道。相同 3.2 檔拖動，慢拖最終移動 3 檔，快拖桌面移動 6 檔、觸摸模擬移動 8 檔（原生事件調度會影響采樣速度）。下列響應式與 WebKit 條目還記錄此前驗證范圍；本次結果見對應 JSON 報告。

- `node --experimental-strip-types scripts/check-archive-drag.mjs`：小幅移動、逆投影還原任意屏幕方向、連續轉彎、反向、停頓、減少動態效果、快慢速度差與最終吸附、負坐標循環，以及 30／60／120fps 的慣性積分一致性。相同 1.6 檔距離、80ms 與 800ms 兩種輸入，模型測試最終位置為第 10 格與第 2 格。
- `scripts/check-archive-momentum.mjs`：Chromium 實際鼠標與 CDP 觸摸，比較同距離快拖和慢拖，檢查松手后依次跨檔、連續衰減、按住停止、改變方向接管、跨列慣性、鍵盤中止和減少動態效果。報告為 `.tools/array-input/momentum.json`。
- `scripts/check-archive-diagonal.mjs`：桌面鼠標、手機豎屏和橫屏 CDP 觸摸，直接使用實際相機的兩條斜向投影，檢查正反方向、物理間距跟隨，以及同一次拖動中水平、豎直、轉彎、回到起點的屏幕位移。純邏輯檢查補充另一組相機、凍結映射、退化投影與雙向慣性比例。報告為 `.tools/array-input/diagonal.json`。
- `scripts/check-array-input.mjs`：實際 Chromium WebGL 頁面，1920×1080 鼠標與 390×844 CDP 觸摸。檢查不足半格時陣列已經跟隨、松手前切檔、吸附、反向、懸停升起與復原、點擊選擇、滾輪、彈窗隔離、八檔循環、捕獲丟失和多指取消、取消后恢復、詳情旋轉。
- `scripts/check-responsive.mjs`：Chromium 手機橫屏與豎屏原有回歸，包括滑動方向、循環、詳情、正文、查看器和彈窗。
- Windows Playwright WebKit 的 390×844 豎屏完整回歸通過；使用合成 PointerEvent，不代表 iPhone 真機多指行為。初次開發服務器運行在查看器步驟超時，改用固定生產構建后完整通過。
- `scripts/check-loop.mjs`：20,000 次相鄰循環導航；`npm run check:viewport`：視口與原片構圖；`npm run build`：TypeScript、資源與 PWA 構建。

本地截圖和報告在 `.tools/array-input/`、`.tools/responsive/`。手機觸摸驗證屬于桌面瀏覽器模擬，沒有新增 iPhone 真機測試數據。
