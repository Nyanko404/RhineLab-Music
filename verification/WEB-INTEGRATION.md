# 壁紙分支回合網頁主分支

2026-09-11，按用戶授權將 `codex/wallpaper-engine` 的已提交實現合入 `main`，保留兩種構建入口。未包含原工作區未提交的文件橋接實驗與其他改動。

| 功能 | 網頁處理 |
| --- | --- |
| 亮暗配色及卡片波次變色 | 直接合入，設置選擇，保存偏好；詳情、查看器同步 |
| 自適應陣列、逐實例裁剪、暗色霧氣 | 直接合入；顯式原片時間碼對照保留固定陣列 |
| 正常開場鋪屏與移除字幕 | 直接合入，保留網頁版點擊解鎖聲音 |
| 頁腳數字時鐘、滾動測量修復 | 直接合入，時分秒獨立滾動，減少動態效果仍有效 |
| 超級性能模式 | 增加網頁設置，默認關閉，保存到原偏好；獨立于減少動態效果，關閉恢復當前預設或自定義畫質 |
| 資源釋放與材質管理 | 共用修復合入；網頁不提供隱藏檔案場景的桌面開關 |
| 工作臺、待辦、倒計時、專注、媒體文字滾動 | 代碼保留在壁紙入口；網頁繼續以檔案瀏覽為主 |
| 系統音頻律動、媒體回調、宿主暫停與幀率 | 僅壁紙構建初始化，普通網頁不偽造系統輸入 |
| HUD、顆粒色散、界面邊距、自定義圖片、3D 開關 | 本次保留為壁紙屬性；網頁如需開放，應另行設計對應的設置入口 |
| PWA、聲音、檢索收藏、導出、觸摸與自定義畫質 | 繼續保留網頁流程 |

- `npm ci --offline` 安裝通過，安裝階段自動應用固定版本滾動庫修補。
- `npm run build`、`npm run build:wallpaper` 均通過。網頁離線包 817 文件、33.8 MiB；壁紙 824 文件、35.1 MiB。保留 Vite 既有大包提示。
- 18 項檔案內容測試通過；視口計算、主題反轉連續性、陣列覆蓋與裁剪檢查通過。
- `scripts/check-web-integration.mjs` 對正式網頁構建運行 Edge：真實點擊啟動、無壁紙宿主初始化、暗色和性能偏好刷新恢復、關閉性能恢復畫質、鍵盤選檔、真實時鐘動畫、詳情和查看器均通過。
- 1600×900、2560×1080、390×844、844×390 視口檢查通過，后面三項未出現頁面橫向溢出。截圖檢查了暗色詳情與手機橫屏布局。這是桌面 Edge 視口模擬，不是新一輪 iPhone 真機測試。
- 網頁 manifest 和生成的 Service Worker 存在，壁紙輸出保持獨立；本輪未重新執行完整離線升級故障矩陣。
- 運行無頁面異常或 THREE／Shader／WebGL 錯誤。結果與截圖位于 `verification/web-integration/`。
