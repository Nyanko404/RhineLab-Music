# 三維模型查看器驗證

開發分支：feat/model-inspector；基于 69f9c99。

## 瀏覽器交互

- 從檔案 X-001 的詳情按鈕進入查看器，模型和當前檔案標簽正常顯示。
- 方向鍵右、上使視角目標從 (0,0,0) 移至約 (0.262,0.350,-0.268)；鼠標滾輪放大使觀察距離由 14.501 降至 11.198。
- 鼠標拖拽越過側面至方位角約 -3.143 弧度，實際檢查了完整背面。Home 將視角、目標與距離恢復至默認值。
- 一鍵拆解后六組部件偏移分別為 2.75、1.85、0.75、-0.15、-1.1、-2.05，默認構圖可看到全部部件，底部操作區可用。
- 一鍵重組后展開系數嚴格為 0，六組偏移全部回到 0；界面顯示「已組裝」。
- 展開系數約 0.290 時反向重組，保留連續運動并順利歸位。
- ESC 返回同一個檔案 X-001，焦點恢復至入口按鈕；再次打開可正常載入并操作。

## 自動檢查

- scripts/check-assembly.mjs 驗證六組部件、原始與裝配資源的雙向表面頂點距離、3.7 的模型高度，以及中途反向重組的連續性與收斂。
- 共檢查 17,954 個原模型表面頂點，最大幾何距離誤差約 6.08e-7，低于 1e-5 容差。
- npm run build、scripts/check-assembly.mjs、scripts/check-appearance.mjs、scripts/check-motion.mjs 全部通過。構建保留既有的包體積提示。

透明部件使用現有實時透射材質，多個透明層間的遞歸折射仍受實時渲染能力限制。

## 光照一致性修訂

- 修復兩個 WebGL renderer 之間直接共享 PMREM 渲染目標紋理導致的環境光缺失；查看器獨立生成與主場景相同的光照環境。
- 對照用戶截圖，實際檢查組裝正面、完整拆解、旋轉和滾輪放大：內部基板、圓環和透明外殼均恢復淺色效果，拆解層次仍可辨認。
- 復用主界面的背景色與氛圍漸變，霧效隨模型觀察距離調整。沒有修改模型資源或材質顏色。
