# 三維資源開關與可選圖片

2026-09-10，壁紙實驗分支。

左下 SESSION 右側的 3D 開關使檔案按行列錯峰下落，約 1.1 秒結束后釋放主場景、獨立查看器、幾何體、材質、紋理、實例緩沖、后處理與渲染器，并主動丟失 WebGL 上下文、移除畫布與場景輸入監聽。再次開啟重新加載資產、恢復選檔，以相同位置軌跡逆向升起。關閉途中可反向；加載中禁用重復加載，失敗回到關閉狀態允許重試。減少動態效果直接切換。

2D 內容繼續運行。游戲入口從退場開始隱藏，載入后按 showgame 恢復；模型查看入口在關閉期間隱藏。已有獨立查看器也隨釋放銷毀，避免隱藏畫布繼續占用資源。

WE「入場與畫面」提供“關閉 3D 后顯示自定義壁紙”（默認關閉）和條件顯示的圖片文件選擇器。圖片按 cover 鋪滿，在資源釋放后約 650ms 淡入；重新加載成功時淡出，加載期間保留。圖片位于 WebGL 畫布之上、普通 UI 之下，使不透明三維背景不會打斷圖片漸隱。支持部分屬性更新、清除路徑、運行中改圖及失敗提示；快速改圖使用請求編號拒絕舊回調。文件路徑根據 [WE 官方 File property 文檔](https://docs.wallpaperengine.io/en/web/customization/properties.html#file-property) 轉為 file:/// 地址。

## 驗證

scripts/check-three-release.mjs 在 Edge 1600×900 實際渲染中通過：

- 關閉中 presence 處于 0–1；反向恢復不觸發 context lost。
- 完整關閉觸發原畫布 webglcontextlost，主場景與查看器畫布數均歸零。
- 新加載產生不同畫布，選檔保留；入場 presence 從小于 1 到達 1。
- 自定義圖片只在關閉后顯示；重開淡出，關閉選項和清除路徑均有效。
- 游戲入口關閉時不可見，重新開啟后恢復。
- 減少動態效果反復開關、查看器用過后釋放、詳情正文繼續可讀以及重新加載均通過；無頁面或著色器錯誤。

截圖與結果在 verification/three-release/。圖片使用測試圖形，未替用戶設置默認自定義圖片。瀏覽器通過模擬宿主回調驗證；WE 原生文件選擇器與真實本地文件加載仍需宿主試用，不將瀏覽器模擬稱為宿主驗收。
