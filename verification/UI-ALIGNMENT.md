# UI 對齊復核 · 2026-09-09

沿用項目的原生 DOM/CSS 實現流程。范圍為導航入口、檢索與收藏彈窗、詳情操作區、設置網格，以及獨立查看器的頁眉和頁腳。

## 修正

- 檢索表頭和結果行共用列定義與 7px 右側留白，表頭和滾動區域均預留穩定的細滾動條空間。原來 10px 滾動條加上結果行獨有的 7px padding，使科室和權限列相對表頭左移 17px。
- 權限文字與箭頭改為水平 flex 居中；箭頭占固定寬度，靠權限列右側排列，避免字號差異造成基線偏移。
- 關閉和搜索符號以 CSS 幾何繪制，保留原有符號輪廓和按鈕語義，避免字體字符自身的留白影響對齊。導航按鈕統一行高與最小高度，快捷鍵框禁止收縮。
- 搜索輸入框清除瀏覽器默認水平 padding；檔案編號禁止壓縮，標題允許在自身列內換行。
- 每個分類按鈕始終預留選中標記空間，切換分類不會改變按鈕寬度或后續文字位置。
- 詳情導出和設置底部操作使用 flex 居中，移除導出箭頭的 float 布局。
- 設置面板預留穩定滾動條空間；音頻和畫質網格均使用 32px 列間距，消除展開高級設置時的橫移及兩組網格的錯位。

瀏覽器驗證為 Chromium；其他瀏覽器的字體柵格化尚未逐一檢查。
