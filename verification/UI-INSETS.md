# 四邊距設置

2026-09-10。用戶因任務欄遮擋底部 UI，要求增加上／下／左／右四個獨立滑桿，并明確允許負數。

WE 屬性新增原生「界面邊距 · 正值內收 / 負值外擴」分組，四項范圍 −300～300px、默認 0、步長 1。數值是原布局額外偏移，通過舞臺縮放換算為顯示區域的 CSS 像素；不是把原邊距替換為 0。部分宿主回調不覆蓋其他方向，非法數值回退 0。

原生 CSS 調整工作臺、檔案與詳情容器的邊界，分別校正品牌、設置、頁腳、固定游戲說明、彈窗和獨立查看器控制區。三維畫布保持原尺寸，字號不因邊距縮放。UI 曲面在邊距布局后測量；開場不受 UI 邊距影響。場景目標與解密標記繼續對應真實模型位置。

驗證：
- 單元檢查覆蓋四方向正負數、超范圍、非有限值、部分回調保留和全零恢復；八個原生分組及條件顯示通過。
- Edge 對照頁在曲面關閉時記錄：基線 brandLeft=46.11、brandTop=89.09、footerBottom=27.35、navRight=46.11。
- 設置上 30、下 60、左 −20、右 40 后分別得到 26.11、119.08、87.34、86.10，誤差約 0.01px。字體均為 44px，三維畫布均為 2139.70×844 CSS px。
- 隨后開啟曲面并切到檔案模式，實際點擊讀取入口成功打開詳情。設置無需開啟視差即可生效。
- 壁紙構建與正式網頁構建均通過；保留既有大塊體積提示。
