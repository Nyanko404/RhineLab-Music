# 聲音重設計與驗證

日期：2026-09-09。交付為原創配樂「Observatory / 觀測室」、16 種程序合成音效、原片短音重構的逐字輸入音效及實際終端集成。

## 依據和邊界

查看本地《明日方舟》特別映像 [萊茵生命：訪問] 的 6.76–40 秒畫面聯系表及現有逐幀記錄；從原文件提取并測量同段聲音。當前代理不能直接聽辨音頻，因此這些結果是畫面觀察、音軌數值分析與原創編配，不是對原曲旋律、樂器或 BPM 的聽寫。后續根據用戶復刻逐字輸入音效的要求，單獨引入三個 38ms 原片短音，詳見下文。

設定參照 [PRTS 收錄的赫默檔案](https://prts.wiki/w/赫默)、[克麗斯騰圖鑒](https://prts.wiki/w/克麗斯騰)，以及項目既有 `reference/LORE-SOURCES.md`。將科研秩序、探索與獨行感轉譯為精細脈沖、開放和聲和稀疏動機，是本次聲音設計的解釋，并非官方對萊茵生命音樂風格的規定。

原片為 25 fps、48 kHz 雙聲道 AAC。`scripts/analyze-reference-audio.mjs` 將左右聲道各取 0.5，解碼為 24 kHz 浮點 PCM 后按視覺段落計算 RMS；輸出見 `reference/audio-analysis.json`。驗證段 11.12–22.76 秒約 −25 dBFS RMS，歡迎頁 22.76–26.92 秒約 −15.92，陣列 26.92–30.68 秒約 −13.05。由此保留「克制驗證 → 歡迎漸強 → 陣列展開 → 特寫收斂」的動態結構；音樂不直接照搬原片的峰值響度。

## 編配

- 原創 72 BPM、4/4、16 小節、53⅓ 秒循環。72 BPM 是本次選擇，不是原片測定速度。
- Dmaj9、Bm11、Gmaj9、Asus2 的開放和聲，后半段以輕微配音變化回答；音符與休止直接寫在生成腳本中。
- `atmosphere.ogg`：低飽和度、緩慢交疊的和聲；`motif.ogg`：帶衰減諧波的鍵音及交錯延遲；`pulse.ogg`：稀疏低頻呼吸與設備點擊。
- 所有音符尾音和早期反射按環形緩沖疊加，三軌使用同一音頻時鐘啟動、同一循環長度。場景切換只改變聲部音量，不重啟音樂。
- 瀏覽狀態三軌比例為 0.9 / 0.72 / 0.65；詳情為 0.72 / 0.36 / 0.12；模型查看為 0.8 / 0.24 / 0.28。啟動段隨原片時間 22.76、26.92、34.3 秒調整編配，約 0.9 秒過渡。
- 總輸出有余量與壓縮保護；抽取、歡迎、陣列和拆組時音樂短暫降低到 65%，約 0.9 秒恢復。

## 設置與生命周期

系統設置提供音效、音樂各自的開關與音量，自動保存。舊版本關閉界面聲音的用戶升級后繼續保持靜音；首次使用會在首次點擊或按鍵后解鎖聲音。瀏覽器禁止無交互自動播放時，先點擊頁面，再重播啟動即可聽到完整流程。

隱藏頁面、離開頁面或全部靜音時暫停音頻上下文，音樂保留位置。重新開啟串行等待先前的 suspend 完成，修復快速切換造成的 resume / suspend 競爭。音樂加載期間再次關閉不會遲到起播；載入失敗可在下一次交互重試，音效獨立工作。音量拖動只保存聲音偏好，不觸發畫質重建。

## 驗證結果

- TypeScript 與 Vite 生產構建通過；原有大 bundle 提示仍存在。
- `reference/audio-check.html` 的瀏覽器檢查全部通過：17 音效的有限樣本、非靜音、峰值與尾端歸零；三軌解碼時長和雙聲道接縫；啟動事件；凍結與倒退；快速輸入；切場景保留音樂；音樂獨立開關；連續開關后的三軌恢復；全靜音暫停和音效清空。
- 解碼后每聲道循環邊界差值小于 0.01，時長誤差小于 2ms；不把該數值結論等同于主觀無縫聽感。
- 在真實主界面檢查了獨立開關、音量控件和設置布局，并操作切檔、切列、讀取、模型拆解與重組。
- 完整開場實機播放結束后：輸入聲 71 / 71，進入詳情、殘留音效為 0，恢復原靜音設置；再次含配樂重播時恰好啟動三軌，中途停止后恢復靜音、上下文暫停、軌道與音效均為 0。
- 聽感尚未由代理人工試聽確認，最終需要用戶以耳機和揚聲器試聽。試聽頁提供 17 種音效按鈕、配樂播放器和原片對照播放器。

## 2026-09-09 · 玻璃質感修訂

用戶進一步明確：交互對象像玻璃，聲音應該清脆。當前音效按這一方向修訂。使用約 1.2ms 接觸起音和五組不等間隔共鳴頻率；高階共鳴更快衰減，最高模式限制在 8.5kHz 以下，加入很輕的 13ms 接觸噪聲。切檔名義尾長 240ms，抽取 580ms，歸位 220ms；指數衰減使實際主體更短。目標是薄玻璃輕碰的清亮感，屬于合成音色設計，不宣稱等同于真實玻璃錄音。

保留原有輸入節流與活動音效上限。試聽頁新增連續 40 次、間隔 55ms 的離線疊音檢查，驗證延長共鳴后仍有峰值余量。背景音樂的音符、聲部與文件沿用上一版。

## 系統反饋與玻璃對象的觸發修訂

用戶接受切換檔案的玻璃方向，并要求檢查作為 OS 的頁面打開、Logo 和文字出現是否使用了合適的音效。當前按操作含義重新綁定：檔案實體的切換、抽取、落定、陣列入場和拆組繼續使用玻璃；檢索、收藏、設置窗口及獨立查看器開合采用電子升降音；內容標簽和模型視角重置采用短電子點擊。沒有給懸停或所有文字更新逐一添加聲音。

開場按原片時間碼觸發：9.16 秒標志啟動和聲，11.84 秒身份確認，19.48 秒掃描，21.84 秒授權確認，22.76 秒歡迎和聲，23.52 / 25.04 秒整塊文字顯現，26.92 秒玻璃陣列，30.68 秒檔案抽取，34.30 秒讀取標記。14.68 / 16.92 秒的通用玻璃點擊已刪除，避免與逐字輸入聲重復。Logo、歡迎、掃描和讀取均不再附加玻璃共鳴。

`reference/boot-audio.html` 提供真實界面的完整開場試聽，從 6.76 秒白場開始；點擊按鈕解鎖瀏覽器聲音，可選擇包含背景音樂。試聽只臨時開啟音效，結束或停止后恢復保存的偏好；不寫入本地設置。同步面板顯示實際發出的輸入聲數量、音頻狀態與完成情況，可與 71 個輸入揭示幀核對。

## 復現

### 逐字輸入的原片短音復刻

用戶指出原視頻中已有逐字輸入聲音，明確要求復刻。本次從視頻約 6.864、6.906、6.948 秒各截取 38ms，位于 `ACCESS PERMISSION REQUIRED` 的開頭。頻譜可見約 40–50ms 間隔的寬頻瞬態，在約 6–11kHz 有較強能量；此前玻璃模式不足以表達這一特征。

短音只做去直流、0.35ms 入端淡變、3.5ms 出端淡變和統一增益；三個樣本之間保留原相對強弱，不做變調、去噪或速度調整。源音來自成片混音，不保證獲得了原制作中的獨立音效分軌；代理未能進行直接人工聽辨。三段原始 PCM 共約 11KB，隨代碼嵌入，首次輸入不依賴異步下載；每個音頻上下文只解碼一次并輪替播放。保留原片來源與處理記錄，見 `public/audio/typing-source.json`。

輸入幀從真實 `bootMotion` 的文字揭示推導，覆蓋首句、ID、姓名、請求、處理和省略號。修正 65ms 節流使 40ms 相鄰輸入漏拍的問題；新行首字也有聲音，19.16 秒附近的故障閃動與文字恢復不視為新輸入。多字符同幀顯示只觸發一個短音；幀卡頓不積壓補發一串聲音。試聽頁新增原片 0.55 秒片段和重排輸入串，方便核對音色。

檢查增加 25Hz 密集輸入的波形峰值、所有字段首字、文字恢復不誤觸發，以及正常播放時輸入幀數量。此前玻璃卡片交互繼續使用獨立的合成音色。

```powershell
node scripts/extract-typing-audio.mjs 'D:/Program Files/CueWeave/resources/tools/ffmpeg.exe'
node scripts/render-audio.mjs 'D:/Program Files/CueWeave/resources/tools/ffmpeg.exe'
node scripts/analyze-reference-audio.mjs 'D:/Program Files/CueWeave/resources/tools/ffmpeg.exe'

```

生成器僅需要 Node.js；參數為本機 FFmpeg 路徑，用于 Ogg / MP3 編碼。省略參數仍可在 `.tools/audio-render/` 生成無損 WAV 母帶。生成腳本使用固定隨機種子；同一工具版本可復現。生產只讀取原創三軌 Ogg（合計約 1.6MB），試聽 MP3 另約 1.3MB，不在運行時加載原視頻。
