# 第一版內構恢復與磨砂修正 · 2026-09-09

用戶最終選擇截圖中對照頁左側第一版完整內構，要求恢復該版本，并反饋磨砂比原片更重。

## 實現

- 從 89c7742 的原始腳本恢復兩組圓環及雙連接帶，保留全部原始幾何、平滑法線、白色和橙色材質。通過 Blender MCP 重新生成單體、六組拆解模型及兩個 .blend 源文件。
- 外殼保留已完成的齊平黃色嵌片、兩處螺絲、蓋板后刻線。reference/ring-study/assembly-before.glb 保存 dde61fd 外殼回歸基準。
- 選中蓋板粗糙度降至 0.42；折射采樣模糊上限約為投影蓋板高度的 1.6%，小尺寸預覽與大尺寸展示采用一致比例。清晰過程單調減輕模糊，保留陣列與完全清晰端原始采樣。
- reference/internal-review.html 同時展示原始第一版和恢復后的第一版。reference/decryption-review.html 可與原片按幀觀察磨砂及清晰過渡。

## 驗證

- check-internal-optics 比較當前與第一版的內部世界坐標、法線、原始材質，以及當前與 dde61fd 的外殼坐標、法線和材質，精度為 1e-5。
- check-decryption 覆蓋解密曲線、蓋板清晰控制、內構深度、折射采樣與著色器替換；新增半尺寸、標準、雙倍尺寸的模糊比例與單調性檢查。
- check-assembly、check-shell 分別檢查單體／拆解幾何一致性與外殼細節、移動揭示。

原片仍存在幾何、照明與實時折射近似差異。技術驗證不代表用戶已經確認磨砂最終觀感。

最終結果：四項腳本檢查通過；單體與拆解最大頂點差為 2.666e-7，高度 3.70000005，內構深度 -0.034 至 0.150。瀏覽器 8 項交互回歸全部通過，覆蓋解密、玻璃切換、快速反向、拆解中切換、退出與重新進入。原片 34.00 秒并排復核可辨識兩組環體；第一版恢復對照兩側內構外觀一致。

生產構建 npm run build 通過，保留既有包體大小提示。最終瀏覽器復核無著色器編譯錯誤。

用戶最終反饋：‘效果很不錯’，確認保留恢復后的內構與本版磨砂效果。
