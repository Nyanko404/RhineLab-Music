# 原片模型細化 · 2026-09-09

本輪按用戶要求放大原片模型，沿用逐幀觀察與 Blender MCP 流程。參考為原片 37、39 秒特寫、39 秒頂部放大及既有端面放大 reference/edge-study.png。對照頁包含 27.60、29.16、31.48、39.00 秒。

## 幾何調整

- 兩個光學環由壓扁圓管改為閉合旋轉截面，區分寬腔壁、斜肩、內孔臺階與細環；主截面采用 128 段。小環的香檳色嵌件保持在透明蓋板后方。
- 頂部壓槽沿參考增加折返與雙側槽邊，放到蓋板內側；增加內周邊、前沿細階、框架接縫和刻度區支點。
- 螺釘由球面頭與疊加黑條改為倒角圓柱、真實布爾凹槽和沉頭墊圈。
- 材質名稱、基線顏色和光照不變；共享標志、外包圍盒、鏡頭及抽取運動沿用。
- 主模型與六組拆解資源均由 Blender MCP 執行腳本導出。使用 bpy.data.libraries.write 保存目標場景及依賴，不保存其他工作場景，也不更改當前打開文件路徑。

## 復現與對照

通過 Blender MCP 在 Blender 內先執行 art/build_archive.py，再執行 art/build_assembly.py，分別提供腳本絕對路徑 __file__。輸出為 public/assets/archive-cassette.glb、archive-assembly.glb 及對應 art/*.blend。

reference/model-review.html 左側可選擇原視頻或細化前，右側為當前模型。兩邊使用基線燈光、同一時刻、相同相機及 1920×1080 渲染緩沖，支持 2×/3× 裁切放大。舊模型為本輪開始前保存的 reference/model-study/archive-before.glb。原片幀沿用本地 reference/motion，不進入生產構建。ArchiveScene.load 的可選路徑供對照復用生產渲染邏輯，默認仍載入正式資源。
