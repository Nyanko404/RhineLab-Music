# 音樂歸齊與強調色修正

2026-09-10。

壁紙的短交互聲音也可能進入 WE 系統頻譜。播放本地音效時記錄實際音符結束時間與 200ms 回傳余量，在尚未形成音樂活動時忽略該時間內的新頻譜活動；已有音樂繼續響應。音樂強度為零時不驅動歸齊。

歸齊進度同時控制陣列與選中標簽的強調程度，完全歸齊時無強調色。暗色“僅選中強調”根據當前檔案實際升降插值，新選中與歸位副本均連續更新。

scripts/check-local-sound.mjs 復現未過濾時的假音樂起點，驗證自身聲音抑制、持續音樂起動與保留、信號丟失回落。scripts/check-selection-state.mjs 在 Edge 1600×900 使用實際鼠標拖動與模擬宿主頻譜，驗證靜音拖動 flatten=0、新舊檔案強調色出現中間值、全部歸齊無強調及恢復；截圖與結果在 verification/selection-state/。通過的是模擬回傳測試，混合系統音源的最終表現以 WE 實際使用為準。
