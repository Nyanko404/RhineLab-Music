# 檔案內容與設定來源

40 份正文為原創的檔案式改寫，研究記錄中包含圍繞設定提出的觀察重點，并非游戲原文、官方實驗結論或真實世界研究建議。編號僅用于本站編目。未核實的日期改為“跨期資料匯編”；人物字段標為“相關人物”，不虛構項目任命。卡片頁及文本導出均保留對應來源。

核對重點：多蘿西屬于源石技藝應用科；斐爾迪南與能量科相關；結構科的研究內容不能與一般承重結構工程混同。事件和人物經歷跨越多個階段，避免把歷史職務寫成一律同時在任。
