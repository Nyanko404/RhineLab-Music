# RhineLab Music 改造紀錄

上游基底為 `LBEILC/RhineLabUI` 的 `12cc5e4013acb9408f753ff71de6b8492299b7c8`，套件版本為 `1.0.0`。本地改造分支為 `rhinelab-music`。完整 Git 歷史與上游授權均保留。

| 區域 | 改造 |
| --- | --- |
| 網頁入口 | `src/entry.ts` 讓音樂終端成為預設首頁。原始檔案終端、對照網址及 Wallpaper 模式繼續載入原始 `src/main.ts`。 |
| 3D 音樂庫 | `src/music/wall.ts` 使用原本的 `ArchiveScene`、卡片 GLB、相機、射線選取、游標回饋、拖曳、滾輪、慣性、選取波與玻璃著色器。音樂卡片以共用紋理圖集顯示封面、曲名或來源，並可沿用原本的近景檢視。專輯牆亦可在 2D 瀏覽。 |
| 介面 | 音樂導覽、三欄工作區、固定播放控制、行動導覽、鍵盤與表單語意。重用上游品牌資產、MiSans、Rolling Number、頁面轉場及介面音效。主題切換同步至原始 Three.js 場景。 |
| 資料 | IndexedDB 交易同時保存匯入檔案與資料庫記錄，音訊與封面分開讀取。保留跨來源收藏、最近播放、播放位置以及清單順序。 |
| 播放 | `PlayerController` 管理佇列、前後曲、隨機、循環、音量、靜音與 Adapter 生命週期。來源切換時取消前一次載入並銷毀舊實例，忽略遲到事件。 |
| 來源 | 本機 Web Audio、YouTube IFrame／Data API、Bilibili 官方 iframe／授權搜尋端點、Spotify 官方曲目連結。新來源可實作 `Adapter` 介面，再接入曲目來源與搜尋註冊。 |
| 歌詞與視覺化 | 讀取本機標籤、匯入 LRC，支援行級及檔案含字詞時間標記時的字詞高亮。本機音訊使用真實頻譜，外部來源以有標示的純視覺訊號動畫顯示。 |
| 維護 | 沿用 Vite／TypeScript、原始 PWA 及現存檔案校驗流程。新增瀏覽器音訊標籤解析套件及 Playwright 驗收測試。 |

三維渲染保留原始畫質，另提供效能及關閉選項。偵測到軟體 WebGL 渲染時使用上游效能配置及原模型的低細節版本。超出可視範圍或切至背景時暫停繪製，切至 2D 時釋放 WebGL 資源。關閉 3D 或環境缺乏 WebGL 時仍可透過歌曲列表及專輯牆操作。

上游場景模型、標誌、字體、音效、配樂與樣本保留其原始授權及署名。首頁試聽使用上游原創的 `observatory-preview.mp3`。音樂介面啟用時使用上游合成介面音效。 [原始授權](../LICENSE) · [上游第三方素材說明](../README.md#許可證) · [音訊來源](../public/audio/README.md)
